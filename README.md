# Robin Screening WebAR

Independent 8th Wall pilot for a Robin-led, sex-neutral screening journey. This project does not replace or modify `Robin-WebAR`.

Run `npm ci`, then `npm run serve`. Use the 8th Wall device connection workflow for camera and world-tracking tests.

Pulse frames and estimates remain in the active browser session. Production analytics use an allow-listed adapter and remain disabled unless a privacy-approved Plausible configuration is supplied.
